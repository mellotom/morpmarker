morpmarker v5.0
I

[ morpmarker_v5.0 - 2026.08.31 ]

morpmarker is the solution to the tedious process of writing splice markers to audio files via manually placed markers in a software that does not operate intuitively to the ableton user. This device takes any audio file and writes splice markers to the file based on information provided by ableton and settings determined by the end user.

[ quick_operation ] :

  1. Prepare your audio file in Ableton by warping the file to match your session’s tempo or by manually placing warp markers in the locations that the splice markers should be written to.
  2. In the Splice Marker Origin Toggle [ 6 ], choose one of the following options :
tempo_synced
  • Select the division at which morpmarker should place the markers.
  • By default, this is set to 1 Bar.
[ note ] : morpmarker treats the selected clip start as 0:00.00, it does not take into consideration where the clip is relative to the gridlines of your session. If the selected file has leading content that does not align with the grid you plan to operate in, it is recommended to select the clip + the leading space between the nearest major gridline and consolidate the audio to add blank leader space and ensure that the markers will be placed at the expected locations.
warp_markers
  • This mode will read the active warp markers in the selected clip’s audio. Transient markers created by Ableton’s transient detection system do not get written to clip. If you would like one of these markers to be written to clip, double click it to create a warp marker.
3.Select an option for blank_splice_insertion [ 5 ].
  • The default [ seamless_playback ] mode ensures that a morphagene patch with a trigger on the shift input will always loop seamlessly through each splice.
  • Alternatively, the [ include_blank_splice ] mode creates an additional splice marker at the very end of the loop that the morphagene treats as a splice with no audio. This will

IV

[ understanding_operation ] :

The default settings of the morpmarker are configured to be able to drop an audio file into ableton, warp the file to the session’s tempo, and press the process button to capture each “phrase” of the audio file as a single splice for the morphagene.

Above is a visual representation of the expected behavior of the default morpmarker settings.

With the [ splice_marker_division ] set to 1 Bar, a splice marker is dropped at each bar.

With [ seamless_playback ] selected, no splice is added to the end of the file.

[ include_blank_splice ] simply adds a silent splice at the end of the file. This is particularly useful for indicating that the each splice marker has been cycled through and the user can stop playback of the device or re-initialize the morphagene & accompanying modules for recording.

Pressing the [ process ] button results in a save dialog for selecting the location of the final prepped file.

The [ splice_marker_division ] options allow you to change the frequency of the splice marker placement based on a division of the master BPM. The goal of this feature is to allow the user to match the length of the splice to the length of the phrase within the sample, allowing for fine control over when the new phase begins in the patch.

[ note ] : try providing a trigger into the shift input every four bars while modulating the gene size and position parameters.

Consider configuring your options.txt to set play input ( pmod ) to playback upon receiving a high gate for further taming of the output. I recommend setting pmod to 1, although 2 could yield interesting results based on your desired outcome.

Use the warp markers option for when you would prefer to dictate exactly when the splice markers are placed in the file.

The faint grey transient markers seen in the image above are not considered by the morpmarker, only the warp markers with green flags seen above are used in this mode.

[ note ] : the morphagene’s hardcoded limits still stand.
A file with more than 299 markers will be rejected.
